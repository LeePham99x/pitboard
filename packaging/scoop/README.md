# datlechin's Scoop bucket

[Pitboard](https://github.com/datlechin/pitboard) switches Claude Code and Codex between your
own accounts without signing out, and shows what each account has left. This bucket holds its
command line for Windows, `pitboard`, at the latest release. Betas are not in it.

Pitboard's release writes every file here from `packaging/scoop/` in Pitboard's repository.
A change made here is replaced at the next release.

## Install

```powershell
scoop bucket add pitboard https://github.com/datlechin/scoop-bucket
scoop install pitboard/pitboard
```

## Documentation

For other ways to install Pitboard, see [Install Pitboard](https://docs.usepitboard.com/install).
Report a problem with the manifest as an
